## Overview

This course provided a beginner-friendly introduction to **SQL**, the language used to query and manage relational databases. I learned how to write SQL statements to retrieve, filter, sort, and manipulate data stored in tables.

Although Coursera does not retain code after submission, I successfully completed all graded assignments and quizzes with full marks.

---

## Key Concepts Learned

- Relational database basics
- SQL data types and table schemas
- Writing basic SQL statements:
  - `SELECT`, `INSERT`, `DELETE`, `UPDATE`
- Filtering data with `WHERE`, `AND`, `OR`, and wildcards (`LIKE`)
- Sorting and limiting results with `ORDER BY` and `LIMIT`
- Joining data across multiple tables using `JOIN`
- Understanding primary keys, foreign keys, and relationships
- Aggregation functions: `COUNT()`, `SUM()`, `AVG()`, `GROUP BY`
